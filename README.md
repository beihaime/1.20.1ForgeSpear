# ForgeSpear

A Forge 1.20.1 mod that ports the vanilla spear from Minecraft 1.21.11 to Minecraft 1.20.1.

## Features

- Wooden Spear
- Stone Spear
- Iron Spear
- Golden Spear
- Diamond Spear
- Netherite Spear
- Custom crafting recipes
- Smithing upgrades
- Creative Tab integration

## Version

- Minecraft: 1.20.1
- Forge
- Ported from: Minecraft 1.21.11
